# Fixed Assets

Track and manage firm assets like computers, furniture, vehicles, and leasehold improvements.

## What you can do here

- Register new assets with purchase cost and date
- Organize assets by category and department
- Track asset depreciation over time
- Monitor asset book value and accumulated depreciation
- Generate asset inventory reports

## Common workflows

**To add an asset:** Enter the asset name, category, purchase cost, and acquisition date, then save.

**To depreciate an asset:** Set the depreciation method and useful life; the system calculates monthly depreciation automatically.

**To view asset value:** Check the dashboard to see total asset value, accumulated depreciation, and book value by category.

## Tips

- Use consistent asset naming conventions for easier tracking and reconciliation
- Set up depreciation policies upfront to ensure accurate period-end adjustments
- Review assets quarterly to identify fully depreciated items for potential disposal
