# Revenue Analysis Report

Analyze invoice revenue across two dimensions simultaneously using a pivot table — for example, solutions by month, or offices by quarter.

## What you can do here

- Pivot revenue data across any two dimensions: time, solution, solution line, office, or office area
- Choose which dimension appears as column headers (primary) and which as rows
- Select period presets: this month, last month, this quarter, last quarter, this year, or custom range
- Drill into any cell to see the underlying invoices
- Export the full pivot table to CSV for further analysis

## Common workflows

**To see monthly revenue by solution:** Set the primary dimension to time (monthly) and the row dimension to solution.

**To compare offices by quarter:** Set the primary dimension to office and the row dimension to time (quarterly).

**To review a solution line breakdown:** Set the row dimension to solution line to group solutions by category across your selected time range.

## Tips

- Mark a dimension as primary to make it the column headers — use the dimension with fewer values as primary for a more readable table
- Use office area or solution line groupings to keep the table compact when you have many offices or solutions
- CSV export includes row and column totals, useful for importing into spreadsheet reports
