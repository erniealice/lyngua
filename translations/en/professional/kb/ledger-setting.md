# Accounting Settings

Configure period close settings, account numbering, and default posting rules for the firm.

## What you can do here

- Set fiscal period dates and close status for months and years
- Define account numbering schemes and conventions
- Configure default posting rules for specific accounts
- Set up recurring entry defaults and templates
- Define depreciation methods and useful lives by asset category
- Configure balance sheet and income statement account mappings

## Common workflows

**To configure fiscal periods:** Set the firm's fiscal year start and end dates, then define month-end and year-end close dates.

**To set account numbering:** Define the numbering structure (e.g., 1000-1999 for assets) and conventions for organizing the chart of accounts.

**To establish posting rules:** Create rules that restrict posting to certain accounts or require supporting documentation for sensitive accounts.

**To set depreciation defaults:** Define default depreciation methods and useful lives by asset category to automate depreciation calculations.

## Tips

- Document your account numbering conventions clearly so all team members follow consistent standards
- Lock fiscal periods immediately after month-end close to prevent accidental changes to historical data
- Review settings annually to ensure they align with changes in firm structure or reporting requirements
- Configure depreciation defaults upfront to reduce errors and ensure consistent treatment across all assets
