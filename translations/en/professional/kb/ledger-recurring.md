# Recurring Entries

Manage automatically recurring journal entries for monthly accruals, depreciation, and rent.

## What you can do here

- Create recurring entries that post automatically each period
- Set up depreciation accruals that run monthly or annually
- Define recurring rent, lease, and utility expenses
- Manage recurring revenue accruals and adjustments
- View recurring entry schedules and posting history
- Pause or modify recurring entries without deleting history

## Common workflows

**To create a recurring entry:** Set up a template entry with accounts and amounts, then define the frequency and start date for automatic posting.

**To record monthly depreciation:** Create a recurring entry that posts depreciation expense and accumulated depreciation each month based on your asset schedule.

**To adjust a recurring entry:** Modify the template or frequency, then choose whether changes apply to future periods or all periods.

**To track posting history:** View the audit log of all entries posted by the recurring template to verify accuracy and amounts.

## Tips

- Set up recurring entries at the start of the fiscal year to ensure consistent period adjustments
- Use meaningful descriptions in recurring templates to identify them in the GL and journals
- Review recurring entry postings monthly to catch any errors before month-end close
- Archive or pause recurring entries when the underlying business event ends
