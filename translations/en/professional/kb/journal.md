# Journal Entries

Create and manage manual accounting journal entries for period adjustments, accruals, and corrections.

## What you can do here

- Create new journal entries with debit and credit lines
- Enter multiple line items per entry
- Add entry descriptions and supporting documentation
- Track entry approval status and approvers
- Search and filter entries by date, account, or description
- Reverse prior period entries
- Post or hold entries for review

## Common workflows

**To create an entry:** Add the entry date, select accounts, enter debit and credit amounts, then save.

**To record an accrual:** Create an entry with the accrual account and matching revenue or expense account.

**To correct an error:** Post a reversing entry to undo the original posting, then post the corrected entry.

## Tips

- Use clear, descriptive entry descriptions to document the business purpose and support audit inquiries
- Balance all entries before posting; the system prevents posting of unbalanced entries
- Route significant or period-close entries through an approval workflow before posting to ensure accuracy
