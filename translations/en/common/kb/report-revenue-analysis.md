# Revenue Analysis Report

Analyze revenue across two dimensions simultaneously using a pivot table — for example, products by month, or locations by quarter.

## What you can do here

- Pivot revenue data across any two dimensions: time, product, product line, location, or location area
- Choose which dimension appears as column headers (primary) and which as rows
- Select period presets: this month, last month, this quarter, last quarter, this year, or custom range
- Drill into any cell to see the underlying sales
- Export the full pivot table to CSV for further analysis

## Common workflows

**To see monthly revenue by product:** Set the primary dimension to time (monthly) and the row dimension to product.

**To compare locations by quarter:** Set the primary dimension to location and the row dimension to time (quarterly).

**To review a product line breakdown:** Set the row dimension to product line to group products by category across your selected time range.

## Tips

- Mark a dimension as primary to make it the column headers — use the dimension with fewer values as primary for a more readable table
- Use location area or product line groupings to keep the table compact when you have many locations or products
- CSV export includes row and column totals, useful for importing into spreadsheet reports
