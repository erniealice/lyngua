# Account Details

View the complete details of a general ledger account, including balance, transaction history, and configuration.

## What you can do here

- View account number, name, type, and description
- See current balance and opening balance for the period
- View chronological transaction list with posting date and amount
- Filter transactions by date range or transaction type
- View related journal entries and supporting documents
- Edit account description or deactivate the account
- Export account transaction history for reconciliation

## Common workflows

**To review account transactions:** Open the account and select the Transactions tab to see all debits and credits.

**To filter transactions:** Use the date range and type filters to find specific transactions (invoice, payment, adjustment, etc.).

**To export transaction detail:** Click Export to download account history for reconciliation with bank statements or other source documents.

## Tips

- Account balance is the sum of all posted transactions since the account was created
- Filtering by transaction type helps identify which source documents created each change
- Exporting account detail supports bank reconciliation and financial audits
