# Events & Schedule

Create and manage calendar events, appointments, and scheduled activities across your organization.

## What you can do here

- View all events in calendar, list, or agenda view
- Create new events with date, time, duration, and attendees
- Search events by name, date range, or assigned participant
- Filter events by type (meeting, appointment, reminder, task)
- Set recurring events (daily, weekly, monthly, yearly)
- Attach notes, documents, or links to events
- Export calendar or event details for sharing

## Common workflows

**To create an event:** Click Add Event, fill in the title, date, time, and attendees, then save.

**To set up a recurring event:** When creating an event, select the Recurring option and set the pattern (daily, weekly, monthly, yearly).

**To invite attendees:** Add email addresses in the Attendees field; invitations are sent automatically to the provided contacts.

## Tips

- Events can be tied to specific clients, projects, or orders for better context
- Use event reminders and notifications to stay on track with important activities
- Color-coding by event type makes calendar views easier to scan and prioritize
