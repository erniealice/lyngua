# Event Details

View and manage the full details of a calendar event, including attendees, notes, and status.

## What you can do here

- View event title, date, time, duration, and location
- See all attendees and their RSVP status
- Add or remove attendees and send updated invitations
- Update event details (date, time, description, location)
- Attach documents, files, or notes to the event
- View activity log showing who updated the event and when
- Mark event as complete or cancel it

## Common workflows

**To update an event:** Click Edit, make changes to the date, time, attendees, or description, then save.

**To add attendees:** Click Add Attendees, enter email addresses, and send invitations.

**To attach a document:** Use the Attachments section to upload or link files related to the event.

## Tips

- RSVP status helps you confirm attendance and plan resources
- Event descriptions and notes provide context for all participants
- Completed or cancelled events are retained in history for audit and reference purposes
