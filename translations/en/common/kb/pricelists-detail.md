# Price List Detail

View and manage the products and pricing tiers within a price list.

## What you can do here

- View all products included in this price list with their prices
- Add or remove products from the price list
- Set individual prices for each product and variant
- Configure pricing tiers or volume discounts
- Edit the price list name, description, and status

## Common workflows

**To add a product:** Click Add Product, select from the catalog, and set the price.

**To update a price:** Click on the price value for any product in the list and enter the new amount.

## Tips

- Price changes take effect immediately for new transactions once the list is active
- Products not included in a price list fall back to their base price
- You can bulk-import prices using the import tool if available
