# Inventory Item Detail

View item details, serial numbers, transactions, and depreciation records.

## What you can do here

- View and edit item information (name, description, category, unit cost)
- Track serial numbers associated with the item
- Review inventory transaction history (receipts, adjustments, transfers)
- View depreciation schedules for fixed assets
- See current stock levels by location

## Common workflows

**To record a stock adjustment:** Select the Transactions tab and click Add Transaction to log a receipt, adjustment, or transfer.

**To view serial numbers:** Select the Serials tab to see all tracked serial numbers and their current status.

## Tips

- Every stock change is recorded as a transaction — use the history to investigate discrepancies
- Depreciation applies only to items classified as fixed assets
- Serial number tracking is optional and can be enabled per item
