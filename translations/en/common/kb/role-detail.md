# Role Detail

View and configure a role's permissions and assigned users.

## What you can do here

- View and edit the role name and description
- Configure granular permissions by module (view, create, edit, delete)
- See all users currently assigned to this role
- Add or remove users from the role

## Common workflows

**To update permissions:** Select the Permissions tab and toggle individual permissions on or off.

**To assign users:** Select the Users tab and click Add User to assign this role to additional team members.

## Tips

- Permission changes apply immediately to all users with this role
- Use the Permissions tab to audit exactly what access a role grants
- A user can hold multiple roles — their effective permissions are the union of all assigned roles
