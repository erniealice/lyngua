# Transaction Detail

View transaction line items, payments, and receipt information.

## What you can do here

- View the full list of line items with quantities and amounts
- See payment details (method, amount, change, tips)
- Access or print the receipt
- View the associated client record
- Check the transaction timeline and status history

## Common workflows

**To view the receipt:** Click the Receipt or Print button to see the formatted receipt.

**To void the transaction:** Use the Void action if the transaction needs to be cancelled (requires appropriate permissions).

## Tips

- Line item prices reflect the price list that was active at the time of the transaction
- Partial payments are shown individually with their payment method
- The transaction timeline shows when the transaction was created, modified, or voided
