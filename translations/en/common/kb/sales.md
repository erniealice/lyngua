# Sales

View and manage sales and revenue transactions.

## What you can do here

- View all transactions by status (completed, pending, voided)
- Search by reference number or client name
- Filter transactions by date range, amount, or status
- View itemized details and payment breakdowns
- Access receipts and transaction records

## Common workflows

**To find a transaction:** Use the search bar to look up a reference number or client name.

**To filter by date:** Use the date range filter to narrow results to a specific period.

## Tips

- Completed transactions cannot be edited — use a credit note or adjustment for corrections
- Reference numbers are generated automatically when a transaction is created
- Use status filters to quickly find pending or voided transactions that need attention
