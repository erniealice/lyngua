# Recurring Entries

Set up automatic recurring journal entries to record regular adjustments, accruals, and expenses that repeat on a fixed schedule.

## What you can do here

- View all recurring entry templates by status (active, inactive, archived)
- Create new recurring entries with pattern (daily, weekly, monthly, quarterly, yearly)
- Configure the accounts, amounts, and description for each recurring entry
- Set start and end dates for the recurring period
- Edit or pause recurring entries
- View history of generated entries
- Configure approval workflows for auto-posted entries

## Common workflows

**To create a recurring entry:** Click Add Recurring Entry, set the posting pattern (e.g., monthly), fill in the debit/credit lines, and specify the start date.

**To view generated entries:** Open a recurring template and select the History tab to see all entries created from this template.

**To pause or resume:** Edit the recurring template and change its status to inactive to stop generating entries, or reactivate to resume.

## Tips

- Recurring entries automate routine adjustments like monthly rent, depreciation, or accruals
- Each generated entry is a full journal entry that can be reviewed and edited if needed
- Pausing a recurring entry does not affect entries already generated
