# Client Detail

View and edit a specific client's profile, history, and categories.

## What you can do here

- View and update contact information (name, email, phone, address)
- See transaction history and lifetime spend
- Manage client tags and categories
- View attached documents and notes
- Check activity log for recent interactions

## Common workflows

**To edit client details:** Click the Edit button on the profile section and update the fields.

**To view transaction history:** Select the Revenue tab to see all completed and pending transactions.

## Tips

- Changes to client details are saved immediately and reflected across all linked records
- The lifetime spend figure includes only completed transactions
- Use the activity log to track when the client was last contacted or updated
