# Locations

Manage your business locations and branches.

## What you can do here

- View all locations and their current status
- Add new locations with address and contact details
- Edit location information and operating hours
- Assign users and inventory to specific locations
- Set a default location for new transactions

## Common workflows

**To add a new location:** Click Add Location in the toolbar and fill in the address and contact details.

**To set a default location:** Open the location detail and enable the Default flag.

## Tips

- Each transaction and inventory record is associated with a location
- Disabling a location prevents it from being selected for new transactions
- Use location-specific reports to compare performance across branches
