# User Detail

View a user's profile, assigned roles, and workspace membership.

## What you can do here

- View and update user profile information
- See all roles currently assigned to the user
- Add or remove role assignments
- View workspace membership details
- Check activity history for the user

## Common workflows

**To assign a role:** Select the Roles tab and click Add Role, then choose from available roles.

**To remove a role:** Open the Roles tab, find the role, and click Remove.

## Tips

- Removing all roles from a user effectively revokes their access to features
- Role changes take effect on the user's next page load
- The activity log shows login history and recent actions performed by the user
