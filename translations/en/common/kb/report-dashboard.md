# Financial Dashboard

View a summary dashboard of key financial metrics, performance indicators, and trends at a glance.

## What you can do here

- See current period and year-to-date revenue, profit, and cash flow
- View financial performance trends over recent periods
- Monitor key metrics (gross margin, operating margin, return on assets)
- Access quick-access reports and detailed analyses
- Set custom dashboard widgets and KPIs
- View balance sheet snapshot (assets, liabilities, equity)
- Drill down into detail reports from dashboard cards

## Common workflows

**To review financial health:** Open the dashboard to see revenue, expenses, profit, and margin trends at a glance.

**To access a detailed report:** Click on any metric card to open the full report with additional filtering and detail options.

**To customize the dashboard:** Use the Edit Dashboard option to add or remove widgets based on your monitoring needs.

## Tips

- Dashboard metrics update regularly as transactions are posted, providing near-real-time visibility
- Comparing current period to prior year helps identify trends and seasonal patterns
- Dashboard drills help quickly investigate unusual spikes or drops in performance
