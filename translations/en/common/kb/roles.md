# Roles

Manage permission roles that control what users can see and do.

## What you can do here

- View all roles defined in the workspace
- Create new roles with custom permission sets
- Edit role names and descriptions
- Delete roles that are no longer needed
- See how many users are assigned to each role

## Common workflows

**To create a new role:** Click Add Role in the toolbar, provide a name and description, then configure permissions.

**To see who has a role:** Open the role detail page and check the Users tab.

## Tips

- Deleting a role removes it from all assigned users — reassign them first
- Use descriptive role names so it is clear what access each role grants
- Start with broad roles and refine permissions as your team grows
