# Journal Entry Details

View and manage the full details of a journal entry, including all debit and credit lines and supporting documentation.

## What you can do here

- View entry date, posting date, and current status (draft, posted, reversed)
- See all debit and credit lines with account number and amount
- View the entry description and any attachments
- Edit the entry (if not posted) or add details to a draft
- Review audit trail showing who created and posted the entry
- Attach supporting documents (receipts, invoices, approvals)
- Void or reverse the entry if needed

## Common workflows

**To edit a journal entry:** If the entry is still in draft status, click Edit, make changes to lines, and save.

**To add supporting documents:** Click Attachments and upload or link documents that support the entry (e.g., accrual schedules, approval forms).

**To verify balancing:** The status bar shows total debits and total credits; they must be equal before posting.

## Tips

- Supporting documentation helps auditors understand the rationale behind manual adjustments
- Reversed entries create an audit trail showing both the original and offsetting entry
- Entries in draft status can be edited freely; once posted, reversals create a permanent audit record
