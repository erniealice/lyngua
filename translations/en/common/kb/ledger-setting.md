# Accounting Settings

Configure your accounting system, including fiscal periods, currency, reporting standards, and posting rules.

## What you can do here

- View and configure base currency for accounting records
- Set fiscal year start date and period definitions
- Enable or disable automated accounting features (tax calculation, depreciation, revenue recognition)
- Configure posting rules and document number sequences
- Set approval workflows for journal entries and adjustments
- Define accounting methods (accrual or cash basis)
- Configure audit trail and transaction logging

## Common workflows

**To set the fiscal year:** Open Fiscal Year Settings, select the start month (January, July, etc.), and the system will define your annual and monthly periods.

**To configure depreciation:** Enable depreciation posting and select the calculation method (straight-line, declining balance) in Asset Settings.

**To enable approval workflows:** Go to Approval Settings and configure required reviewers for journal entries and adjustments above a certain threshold.

## Tips

- Fiscal period settings determine which periods are open for posting and which are closed for reporting
- Changing accounting methods (accrual vs. cash) affects how revenue and expenses are recognized
- Audit trail logging provides a complete record of all posting activities for compliance and investigation
