## [0.1.0-alpha] - 2026-06-15

Translation / i18n package — first published alpha.

### Added
- Translation JSON catalogs with a 3-tier cascade (`common → general → {businessType}`)
  across the supported business types.
- Go loader and knowledge-base (markdown help content) support.
